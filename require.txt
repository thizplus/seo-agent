ผมอยากสร้างระบบ seo agents ที่ทำงานได้แบบ all in one ครับ  ตั้งแต่การวิเคราะห์ website หา ข้อมูลในหน้าเว็บ และสามารถรู้ได้ว่าเว็บนั้น ขายสินค้า หรือให้บริการเกี่ยวกับอะไร
สามารถดึง url ทั้งหมดในหน้าเว็บออกมาได้ๆ คล้ายๆ รู้ sitemap 

และสามารถเขียนบทความ seo ให้รองรับ EEAT ได้ดีครับ รวมถึงสามารถ generate รูปได้ได้ด้วยก็จะดีมาก  โดย ผทใช้ gimini อยู่  คุณสามารถช่วยผมวางแผนทีได้ไหมครับ ว่าจะทำยังไง ที่ผมสามารถ สั่งเปิดทำงานได้เลยบน local และให้มันทำงานได้ตลอดเวลาเมื่อสั่งทำงาน
อาจจะใช้ python หรือ อย่างอื่นช่วยผมก็ไม่ติดครับ 

โดยระบบนี้จะต้องสามารถ add site url เข้าไปได้ โดยสิ่งที่มันจะทำเมื่อ add site

1. วิเคราะห์เว็บทั้งหมด ว่าขาย หรือ ให้บริการ เกี่ยวกับอะไร
2. แนะนำ seo พื้นฐาน
3. แนะนำ หัวข้อบทความที่ควรเขียน เพียงแค่ผมใส่ keyword mี่ต้องการลงไป ให้ relate กับเว็บไว๖์
4. สร้างบทความ + รูปภาพ ได้เลย โดยให้เน้น EEAT 

*** ต้องสามารถ add site ได้ไม่จำกัดครับ เพื่อดู status การสรา้งบทความ หรือข้อมูลเก่าๆได้
